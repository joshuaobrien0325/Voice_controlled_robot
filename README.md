# Voice_controlled_robot
This repository houses my voice controlled robot code and final report which was submitted as part of the completion of my degree in electronic and communications engineering.
This project utilises google speech commmand dataset v2 to train a convolutional neural network to spot 6 directional command and 5 speeds.
A multidirectional robot was then built and connected via BLE to a laptop which processed the voice input and ran the keyword spotting script.
